# 모바일 청첩장

성렬과 소정의 결혼을 위한 반응형 모바일 청첩장입니다. 정적 HTML, CSS, JavaScript로 구성되어 별도 빌드 도구나 의존성 없이 `index.html`을 브라우저에서 열어 확인할 수 있습니다.

## 사진 추가하기

현재 저장소에는 개인 사진이 없어 메인 이미지 영역과 갤러리 30곳을 사진 자리로 준비했습니다. 두 사람의 사진을 제공받으면 `index.html`의 `.hero-photo`에 메인 이미지 요소를 연결하고, `script.js`의 갤러리 슬롯 렌더링을 실제 이미지 경로로 연결해 주세요. 개인 사진은 임의로 생성하거나 외부 이미지로 대체하지 않습니다.

## 지도

오시는 길 영역은 네이버 지도를 기본으로 표시하며, 네이버 지도·카카오맵·Google Maps 길 찾기 링크를 제공합니다. 외부 지도 서비스가 임베드를 허용하지 않는 환경에서는 지도 바로 아래의 네이버 지도 링크를 이용할 수 있습니다.
